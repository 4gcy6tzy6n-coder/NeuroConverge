## Current scientific position

The manuscript asks which evidential transitions in neural-to-artificial transfer require separate empirical support. It is a retrospective, outcome-informed case synthesis. Its cases have no common estimand and do not jointly test a transfer law. The proposed contribution is the case-level demonstration that comparator identity, effective input information, endpoint semantics and verification depth change which inference a result can support. Whether that contribution is sufficiently new and substantive for NMI has not been established by the current comparison table.

The four synthetic packages retain their frozen outputs. No additional scientific experiment is the default task. This closure status concerns the planned experimental scope; interpretation and reconstruction audits remain active.

## Verification level

Use the levels in [`reproducibility/VERIFICATION_LEVELS.md`](reproducibility/VERIFICATION_LEVELS.md):

- **L1 — integrity:** hashes and package structure.
- **L2 — endpoint/statistics:** stored outputs reproduce reported summaries and inferential results.
- **L3 — input-to-inference:** independent regeneration from retained inputs through endpoint and inference.

The V1 independent audit reaches L3 for one seed, one sample size, one split and five conditions (5/900 endpoint cells); it is not full package reconstruction. M0 currently supports stored-output recomputation but lacks the source inputs and execution record required for L3. Do not describe either package as completely end-to-end reproducible.
