## Supplementary Methods S1 — Retrospective portfolio selection

This integration is a retrospective, source-linked synthesis, not a systematic review or prospectively unified biological experiment. The main-text cases were selected to illustrate distinct evidence transitions and include both supported and unsupported outcomes; this selection was made with knowledge of earlier project outcomes and is not an outcome-independent sample of the portfolios. The initial synthesis and M2/M5 tests were followed by a post-result DMP fast–slow × correspondence module and a source-informed V1 PC→SST figure/ground package. Each local protocol was frozen before its own outcome run, but all were designed after earlier project results had been inspected; none is project-level preregistration or independent biological confirmation. The V1 protocol's AP interaction interpretation had a sign-direction wording error, preserved and disclosed in its post-run amendment. Each Route-D portfolio record retains its original evidence class, unit, task, comparator, status (including invalid, blocked, or outcome-informed), and correction history in Table S1. Selected branch records are accounted for separately in Table S2; unresolved C08-to-M10 identity is not used to support a claim. A record's presence in the portfolio matrix does not imply that it supports the central claim. Supplementary-only and excluded records remain visible in the disposition accounting, including RR18/RR19 as separately governed exclusions. No common effect or meta-analysis is calculated because the tasks, outcomes, units and sampling structures are not exchangeable.

## Supplementary Methods S3 — Cerebellar source-readout reanalysis

This post-result exploratory analysis used the released Dryad v4 file `learning_1s_to_2s_GrC_CF.mat` [10] and source-code-derived plasticity computation. All sessions in the three released groups were included: five 1-s expert sessions, five 2-s novice/1-s expert sessions and six 2-s expert sessions. Eligible rewarded trials satisfied the source `mvlen > 7` and `goodmvdir` criteria. Each session used five deterministic random 50/50 trial splits, with seed `20261001 + 100000g + 1000s + k` using zero-based group, session and split indices. Climbing-fibre selection, activity scaling and readout weights were fitted only on training trials.

Candidate climbing fibres showed a reward-aligned event increase in [0, 0.25] s relative to [−0.3, −0.025] s. The source plasticity computation used granule-cell activity in [−0.15, −0.025] s before teaching events, with rounded frame offsets and inclusive window endpoints. Activity was rectified, scaled by training-cell 95th percentiles, transformed with the source logistic function, averaged and normalized per selected climbing fibre, then averaged with the source negative sign. These weights were modeled proxies under the inherited connectivity assumption. Held-out readouts used movement-midpoint-aligned activity through the recorded reward delay, capped at 2 s, and squared Pearson correlation with elapsed time. Uniform, cell-shuffled and timing-shuffled controls and a training-standardized ridge reference with α = 1.0 were evaluated on the same held-out trials. Valid trial scores were averaged within split, splits within session and sessions within source group. Two splits without training climbing-fibre candidates remained unusable. No animal-level inference was calculated, and the ridge reference was not capacity matched.

The exact package is pinned to NeuroMech `experiment-publication` commit `3e5c458f15b2cad7aa6c5703b1827763e84343bb` and selected-file hashes in `../reproducibility/SELECTED_ARTIFACTS.csv`. Route-D V3 has no exact record for this package and classifies the broader M5_CEREBELLAR line as supplementary-only; this analysis is therefore reported as a separate supplementary branch record and is not included in the 39-row Route-D disposition counts.

## Supplementary Methods S4 — DMP fast–slow correspondence V1

The DMP V1 synthetic extension was motivated by the published fast–slow dual-memory spiking architecture of Sun et al. [13], but was not a reproduction of its algorithm or hardware. Its artificial model combined 32 leaky integrate-and-fire units (leak 0.5, threshold 1, subtractive reset and fixed fast-sigmoid surrogate gradient) with a fixed two-dimensional LMU-like state. The Legendre-derived continuous matrices were discretized by exact zero-order hold at horizon θ = 32. The short-state control retained the same state dimension, fixed input matrix, learnable tensor shapes, initialization scheme, optimizer and update count, but used a 0.5I transition. Slow-state output entered the membrane current through a learned scalar-compressed input. DMP and control parameter counts were 1,286/1,385 for regression/classification; an 18-unit GRU reference had 1,315/1,372 parameters, within 5% of DMP. FLOPs were not matched.

Each generator used four input channels and a 64-step training sequence. In delayed association, a noisy four-level context occupied steps 0–3 and a noisy four-level query occupied steps 36–39; a fixed task-specific permutation of (context + query) mod 4 supplied the class. For state estimation, a stationary unit-variance AR(1) latent trajectory (φ sampled from 0.90–0.98 per task instance) was observed through two channels; a binary context indicated which channel had low (SD 0.25) or high (SD 1.2) noise, and target was the final latent state. Context regime switch probability was sampled from 0.015–0.045. In contextual decision, a four-level context at steps 0–3 selected a task-specific mapping from four noisy evidence votes at steps 36–51 to a class. Longer-delay test sequences had 128 steps: query or evidence moved to steps 68–71 or 68–83, respectively; state-estimation horizon doubled. Configuration seeds were shared across IID and longer-delay generator instances, while trial draws differed.

Each task-instance seed generated 2,048 training, 512 IID test and 512 longer-delay test trials. Training prefixes N = 128, 512 and 2,048 were nested. For every prefix separately, the slow-context stream was reassigned by a no-fixed-point derangement within that prefix; IID and longer-delay splits used independent derangements. This preserved the exact context-stream marginal for each comparison while holding the fast stream, targets and sample count fixed. The intervention broke trial-level pairing and did not change target labels. Two paired initializations were averaged within each task-instance seed.

All learned models used ten fixed epochs, batch size 64, Adam learning rate 0.003 and gradient clipping at five. Within each N, factorial cells used the same task data, update count and paired initializations. Across N in the secondary scaling analysis, fixed epochs meant that update counts increased with sample size: 20, 80 and 320 updates per fit at N=128, 512 and 2,048. The three families used 30 task-instance seeds each. Classification endpoint was test 0–1 loss; state endpoint was test squared error against the unit-variance latent state. The co-primary contrast was I = [L(M+, C−) − L(M+, C+)] − [L(M−, C−) − L(M−, C+)], where M+ is DMP, M− is the short-state control, C+ is aligned and C− is broken correspondence. Each family had a paired task-seed percentile bootstrap 95% interval and two-sided sign-flip P value; Holm correction controlled the three co-primary interactions. Task viability required aligned, full-data GRU loss to be below task-null loss; the three viability P values were also Holm-adjusted. A positive mechanism-specificity gate required a passed viability gate, positive adjusted interaction evidence and a positive aligned DMP advantage. The frozen secondary scaling criterion estimated the within-unit slope of aligned control-minus-DMP loss against log₂(N); its three family P values were Holm-adjusted. It required the N=128 advantage interval above zero, slope interval below zero and adjusted P < 0.05. Because optimizer update count varied with N, this criterion did not isolate sample efficiency. Longer-delay changes were secondary and evaluated without refitting.

The runner, verifier and contract hashes and runtime environment were frozen before confirmatory units. Runtime was Python 3.9.6, NumPy 2.0.2 and PyTorch 2.8.0 on macOS arm64 CPU, deterministic algorithms enabled and one thread. The run produced 7,020 unit-level rows and 7,020 per-trial loss vectors. The independent verifier recalculated all means from raw vectors and checked hashes, task-instance coverage, parameter counts, cell completeness and exact correspondence marginals. The module is a post-result project extension because prior M2/M5 outcomes and the fast–slow literature had been reviewed before it was designed.

## Supplementary Methods S5 — Prospective source-informed V1 figure/ground test

The source paper reports like-to-like functional connectivity from orientation-tuned pyramidal cells to SST interneurons and a causal contribution of SST activity to orientation-dependent surround suppression [14]. The present benchmark did not use recordings from that study. Each 11 × 11 synthetic image contained eight orientation-tuned response channels. A fixed soft tuning function (κ=2) generated channel responses with Gaussian noise (s.d. 0.08), positive clipping and normalization. One randomly placed 3 × 3 figure had an orientation category selected uniformly from the seven alternatives to the background category. Training and IID backgrounds were uniform; the OOD split used the fixed category probabilities `[0.35, 0.25, 0.12, 0.08, 0.07, 0.05, 0.04, 0.04]`. Each of 30 deterministically derived task-instance seeds generated 512 training images, 256 IID test images and 256 OOD images. Nested training prefixes were 32, 128 and 512 images.

At each location, surround activity was the mean of the eight neighbouring locations. The feature-selective transform subtracted 0.65 times the same-channel surround response. In the broken-correspondence arm, channels were routed through a fixed cyclic no-fixed-point permutation. The historical global-pool control subtracted 0.65 times the across-channel mean surround response. Normalization makes each response vector sum to one; its neighbour mean also sums to one, so the pooled scalar is 1/8 in exact arithmetic. This control is a constant offset, `x − 0.65/8`, absorbed by the class-mean-centered linear readout and its intercept. It is effectively local-only, up to floating-point rounding, and not a second functional contextual inhibition mechanism. Global aligned/broken cells are identical by construction; the interaction reduces to selective broken minus selective aligned. Frozen cell names are retained in source files. A regularized linear discriminant (ridge λ=0.02) was fit separately in each factorial cell using the same training images. A generic-context reference received concatenated center and surround channels (16 features) with the same readout; it was not parameter-matched and was not a strong neural-network reference. The frozen prevalence reference was 9/121. AP used stable descending pixel sorting and averaged precision at each positive pixel rank; equal-score ties retained flattened pixel-index order. Thus the actual all-equal-score AP can depend on patch position and is not identically 9/121. Passing the frozen prevalence-reference criterion does not establish contextual learning or rule out structure-preserving no-learning alternatives.

The independent unit was the task-instance seed; image and pixel measurements were nested. The primary endpoint was mean per-image average precision. The frozen interaction was `(AP(selective, broken) − AP(selective, aligned)) − (AP(global, broken) − AP(global, aligned))`. The contract text incorrectly described a positive value as an alignment benefit even though AP is higher-is-better and the contrast is broken-minus-aligned; the numerical formula, outputs and gate were left unchanged. The positive-specificity gate required generic-reference viability, the frozen numerical interaction criterion and higher aligned AP for selective than global pooling. Paired bootstrap CIs used 20,000 task-seed resamples; two-sided sign-flip tests used 100,000 Monte Carlo sign patterns generated by NumPy `default_rng(20261003)`. Scaling and OOD comparisons were secondary. The executed contract, runner, verifier, derived seed schedule, hashes, 230,400 saved per-image AP outcomes and interpretation amendments are in `../new_experiments/PROSPECTIVE_V1/`.

## Supplementary Results S2 — Historical artificial tests and source-readout record

The following numerical account was moved from the earlier main Results or retained from historical source packages. These studies retain their original identities and ceilings; they are not replications of the completed V1 tests. Supplementary Table S2 distinguishes exact hash-pinned branch packages from unresolved cross-branch record relationships. The source-readout endpoint was held-out trial squared Pearson correlation with time progress, a direction-insensitive association rather than calibrated time prediction. Of 80 planned splits, 78 were usable; two retained the status `NO_TRAINING_CF_CANDIDATES`. Source weights were modeled and sessions were not established as independent animals.

In one synthetic switching task, sensory-site motor feedback reached 88.94% accuracy versus 82.14% for an equal-parameter output-persistence control, but did not exceed no-feedback (89.05%), a two-unit generic recurrent model (90.21%), or a task-aware Bayes filter (90.30%). The local contrast therefore identifies a placement-dependent trade-off against one comparator, not an overall accuracy advantage.

In the cerebellar source analysis, model-derived weights exceeded uniform weights in 15/16 source sessions and CF-time-shuffled weights in 16/16; a fixed ridge readout exceeded the source-derived projection in 14/16. This supports within-session predictive temporal structure under the modeled analysis. In the separate synthetic interval task, CF-timed LTD did not meet its frozen transfer criterion: mean held-out absolute error was 0.1252 s versus 0.1097 s for no-trace, 0.1252 s for CF-time-shuffled teaching, 0.1030 s for a generic radial-basis representation, and 0.0753 s for the training-label empirical timer. A design audit found that trial-specific timing jitter was independently sampled and not present in the inputs. The outcome bounds this implementation/task pair; it does not test whether the biological rule could use a suitable trial-specific signal.

Two additional M5 eligibility-trace studies use different synthetic objectives and must not be combined with the source-defined CF-LTD interval experiment. In a delayed-XOR classification task (32 seeds), eligibility traces reached 0.6974 accuracy versus 0.5562 for no-trace and one-step truncated backpropagation through time (TBPTT-1), but trailed TBPTT-4 (0.9633) and full backpropagation (0.9996). In a separate fixed-generator classification suite, trace eligibility exceeded no-trace by 0.2284 (95% interval [0.2213, 0.2357]); exact replay nevertheless outperformed eligibility in all 12 generator-by-delay cells (overall means 0.7609 versus 0.5590). These are post-result synthetic demonstrations that eligibility can help against a weak memory control under some task conditions; the stronger replay and gradient-based controls set a lower ceiling on claims. Neither result validates a cerebellar mechanism or establishes general transfer.

### Frozen eligibility rule, transcribed from the pilot driver

For each control policy `p` and each pilot seed `s`:

```text
mismatch(p, s) = |MAC_p(s) - MAC_treatment(s)| / max(MAC_treatment(s), 1)
p is eligible  <=>  mismatch(p, s) <= 0.01  for EVERY pilot seed s
```

The denominator is the treatment's own realized operation count, which is produced by running the treatment. A control's admissibility is therefore a function of the treatment's realized behaviour rather than of the plan.
