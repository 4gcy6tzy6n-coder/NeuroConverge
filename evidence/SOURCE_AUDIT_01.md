# Source audit 01 — selected claims

**Scope:** M0/Fish1.5 structure evidence, the selected NeuroMech M2 placement contrast and two distinct M5 records. No experiments were rerun.

## Audited findings

- **M0:** the NeuroMotif full-evidence report classifies the whole-connectome result as a bounded negative: no advantage over passive identity-like persistence in its frozen reservoir/value-retention assay. The longer local `PHASE1_FALSIFICATION_REPORT.md` exists in the NeuroMech source workspace at commit `555c064`, SHA-256 `84fda6bd0ab19f733e3be20581fed105d21405cca33fe7b29ac8a463e20dc3eb`; it explains the interference/task boundary. This exact result package is not present in the public NeuroMotif snapshot reviewed, so canonical round artifact linkage remains incomplete.
- **Fish1.5:** public NeuroMotif primary record reports one specimen, 82 neurons, `rho=-0.10961965`, positive permutation `p=0.8337166`, neuron-bootstrap 95% interval `[-0.2932283, 0.1338241]`. Its null family has 139/1000 defined correlations and is invalid/indeterminate. The Fish1.5 post-result null package's local `SHA256SUMS.txt` verified from its own directory. The primary result checksum file embeds an old `/tmp/neuromotif-fish15-experiment1/...` path; direct `shasum -c` from the public repository directory therefore fails on path resolution. This is a portability defect in that checksum list, not evidence that file contents mismatch. File-level hashes are independently recorded in `SELECTED_ARTIFACTS.csv`.
- **M2:** NeuroMech commit `3e5c458` existing verifier returned `PASS`, checking 230,400 episode-policy-hazard keys, recomputing the primary interval, and validating source/output hashes. Accuracy at `h=0.05`: sensory-site 88.94%, output-persistence 82.14%, no-feedback 89.05%, generic 2-unit RNN 90.21%, Bayes filter 90.30%. The round is post-result exploratory and synthetic.
- **M5 source readout:** existing verifier returned `PASS`: six output hashes, 12,355 held-out rows, 392 split records, 5,161 weight rows and 2,471 paired trial records. Session-level descriptive comparisons were recomputed. This is post-result within-session prediction; there is no animal-level generalization or direct synaptic measurement.
- **M5 transfer V2:** existing verifier returned `PASS`: eight output hashes, 96,000 finite episode results, 12,000 paired episode sets, 192 task-seed rows and exact source/contract/runner hashes. The frozen criterion was not met; the experiment authors' post-run audit documents that independent target jitter was absent from input features.
- **M5 delayed-XOR eligibility:** the stored post-run verification record reports a complete 32-seed/five-arm grid, recomputed paired effects and BPTT viability (`passed: true`, 160 task-seed-arm rows). Its result is comparator-dependent: eligibility accuracy 0.6974 versus 0.5562 for no-trace/TBPTT-1, 0.9633 for TBPTT-4 and 0.9996 for full BPTT. Running the source checksum list from the repository root showed most entries passing but an obsolete `README.md` digest and an unavailable convergence-note path; this package is therefore not described as having a wholly clean checksum manifest.
- **M5 fixed-generator generalization:** stored verification reports 1,080/1,080 metric cells, matching frozen hashes, recomputed eligibility-minus-no-trace mean +0.22844 (95% interval [+0.22133,+0.23568]) and positive mean contrasts for all three fixed input generators. Exact replay had higher accuracy than the trace in all 12 generator-by-delay cells (overall 0.76094 vs 0.55896). Scope is fixed-generator generalization within one synthetic classification objective, not arbitrary task-family transfer.
- **M5 delayed-teaching v3 (selection note):** the source `RESULTS.md` reports trace eligibility above no-trace on a separate synthetic delayed-classification task, while exact replay and batch logistic regression were stronger. It is not elevated to a separate main-text claim here because this overlaps the synthetic eligibility story while its current source folder lacks the same package-level verifier evidence as the two selected comparisons. Retain it in the inclusion/exclusion audit before submission rather than silently omit it.

## Interpretation boundary

The above verifies selected source records and archived-output integrity to the level stated per package. It does not complete source-project freeze, reproduce the original runs from raw data, establish that these are the optimal/complete study selection, audit every manuscript sentence, or close licensing/authorship/reproducibility gaps. The `M5_ELIGIBILITY_TRUNCATED_BPTT_V1` root checksum list contains stale/unresolved entries; paper-level file hashes in `SELECTED_ARTIFACTS.csv` pin the selected records but do not repair that source package.
